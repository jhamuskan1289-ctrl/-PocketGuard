# PocketGuard 

### Smart Micro-Savings & Expense Tracker for Students

PocketGuard is a student-focused personal finance management platform designed to make saving money effortless.

It helps college students track expenses, build savings through spare-change round-ups, monitor monthly budgets, and manage shared expenses.

##  Features

- **Smart Micro-Savings:** Automatically calculates spare change from transactions and adds it to savings.
- **UPI/SMS Parser:** Extracts transaction amounts and merchant details from sample or manually entered bank SMS messages.
- **Expense Categorisation:** Automatically categorises expenses into Food, Travel, Academic and Shopping.
- **Budget Tracker:** Monitors monthly spending and remaining allowance.
- **Smart Alerts:** Provides rule-based spending warnings.
- **Peer Split Ledger:** Helps students track shared expenses and settlements.
- **Digital Piggy Bank:** Tracks progress towards savings goals.

##  Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Lucide Icons

##  How to Run

1. Clone this repository.
2. Open `index.html` in your browser.
3. Try the sample SMS messages.
4. Explore the budget tracker and peer split features.

##  Future Scope

##  Current Implementation

This version is an interactive frontend prototype. Transaction parsing uses sample or manually entered SMS text and demo data. It does not connect to real bank accounts.
